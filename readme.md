# 🌤️ Weather App

A simple and responsive **Weather App** built using HTML, CSS and JavaScript.

This project allows users to search for a city and view weather-related information in a clean and simple interface.

## 🚀 Live Demo

👉 https://kulsum25706-prog.github.io/weatherApp/

## 📂 GitHub Repository

👉 https://github.com/kulsum25706-prog/weatherApp

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Display temperature
- 💧 Display humidity
- 🌬️ Display wind speed
- 🌡️ Display pressure
- ☁️ Display weather condition
- 📱 Responsive design
- 🎨 Custom CSS styling
- ⚡ JavaScript-based functionality
- 🖼️ Weather-related images and backgrounds

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
